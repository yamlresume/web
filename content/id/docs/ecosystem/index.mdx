YAMLResume menyediakan paket dan alat yang dapat digunakan kembali untuk membangun alur kerja resume, menyematkan editor, mengotomatiskan build, mengelola contoh, dan mengonversi data resume yang sudah ada.

## @yamlresume/node

[`@yamlresume/node`](./ecosystem/node) adalah runtime Node.js yang dapat digunakan kembali di balik CLI YAMLResume.

- Membaca dan memvalidasi file resume YAML, YML, atau JSON dengan error posisi.
- Membangun tata letak yang dikonfigurasi, memantau file, dan mengompilasi PDF LaTeX atau Typst.
- Membuat resume dari contoh atau menghasilkan dan menerjemahkan file dengan AI.

## @yamlresume/playground

[`@yamlresume/playground`](./ecosystem/playground) adalah komponen React di balik [playground](/id/playground) resmi.

- Menyematkan editor Monaco YAML yang sadar skema dan pratinjau multi-tata letak langsung.
- Menggunakan tata letak desktop dan seluler yang responsif, aksi ekspor, dan label UI terlokalisasi.
- Berintegrasi dengan Vite, Next.js, Tailwind CSS, dan penyiapan worker Monaco kustom.

## create-yamlresume

[create-yamlresume](./ecosystem/create-yamlresume) memudahkan Anda memulai proyek
YAMLResume baru dengan perintah satu baris. Alat ini akan membuat struktur direktori
proyek, menginstal dependensi yang diperlukan, dan menghasilkan file contoh resume
sehingga Anda dapat langsung memulai.

- Merancang proyek baru dengan `npx create-yamlresume my-resume` atau perintah
  serupa untuk `npm`, `yarn`, atau `pnpm`.
- Menyertakan struktur proyek yang siap digunakan, skrip untuk membangun dan
  memvalidasi resume, serta contoh file resume YAML.

## json2yamlresume

[json2yamlresume](./ecosystem/json2yamlresume) adalah alat CLI untuk mengonversi
file [JSON Resume](https://jsonresume.org/) ke format YAMLResume.

- Mengonversi file JSON Resume ke YAMLResume, mengubah struktur dan kolom sesuai
  kebutuhan.
- Memastikan data Anda divalidasi terhadap skema YAMLResume.

Alat-alat ini membantu Anda bermigrasi dari format lain, mengotomatiskan penyiapan
proyek, dan menyederhanakan alur kerja Anda dengan YAMLResume.

## samples

[`@yamlresume/samples`](./ecosystem/samples) menyediakan katalog contoh resume
terkurasi untuk posisi-posisi umum, masing-masing diterjemahkan ke dalam 12
bahasa lokal.

- Mendukung perintah `yamlresume new --sample` dan sub-command
  `yamlresume samples list`.
- Mengekspos API kueri untuk memfilter contoh resume berdasarkan bahasa,
  kategori, atau tag.
