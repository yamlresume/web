Orang-orang di seluruh dunia menggunakan YAMLResume untuk membuat dan
menerbitkan resume mereka. Halaman ini mengumpulkan kasus yang kami ketahui:
resume yang dikelola sebagai YAML di repositori publik, serta alur kerja dan
alat yang dibangun di sekitar CLI.

Ada yang terlewat? [Tambahkan milik Anda](#tambahkan-milik-anda).

## Alur kerja dan otomatisasi

Cara membangun dan menerbitkan resume tanpa menjalankan perintah YAMLResume
secara manual.

- [wldyslw/resume](https://github.com/wldyslw/resume) — otomatisasi dengan
  Makefile dan Docker.
- [anakinkinsey/resume](https://github.com/anakinkinsey/resume) — dibangun
  dengan image Docker resmi dalam satu perintah.
- [conorwithonen/resume](https://github.com/conorwithonen/resume) — Docker dan
  Task untuk resume seorang engineer DevOps.
- [linxing/resume2](https://github.com/linxing/resume2) — YAMLResume plus
  GitHub Actions.
- [mfyz/mfyz-resume](https://github.com/mfyz/mfyz-resume) — toolkit resume
  pribadi berbasis YAMLResume.

## AI dan alat agent

Agent penyesuaian resume dan integrasi LLM yang menghasilkan atau menggunakan
file YAMLResume.

- [zhiweio/resume-as-code](https://github.com/zhiweio/resume-as-code) — pipeline
  berbasis LLM yang mengubah data terstruktur menjadi resume yang disesuaikan.
- [AnxForever/yamlresume](https://github.com/AnxForever/yamlresume) — agent
  penyesuaian berbasis bukti: setiap klaim yang dihasilkan merujuk kembali ke
  materi milik kandidat sendiri.
- [oat431/job-hunting-loop](https://github.com/oat431/job-hunting-loop) — siklus
  pencarian kerja di atas YAMLResume.
- [JoeMattie/job-hunt-kit](https://github.com/JoeMattie/job-hunt-kit) — kit
  pencarian kerja.
- [Remi-Z/resume-composer-gpt](https://github.com/Remi-Z/resume-composer-gpt) —
  plugin Codex lokal untuk resume, CV, dan surat lamaran.
- [downquark7/resume-builder](https://github.com/downquark7/resume-builder) —
  pembuat resume AI yang menghasilkan YAML kompatibel YAMLResume dan memanggil
  CLI untuk keluaran PDF.

## Editor dan manajer

  manajer resume visual yang menyusun resume berbeda dari YAML bertag, lengkap

Halaman ini hanya menautkan konten yang sudah publik. Jika Anda lebih suka tidak
dicantumkan di sini, buka issue dan kami akan menghapusnya.
