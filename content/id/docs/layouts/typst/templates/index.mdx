---
title: Template
description: "Pilih template Typst Jake bawaan dan atur lewat `layouts[].template`."
---

Anda dapat mendaftar semua template YAMLResume, termasuk template Typst, dengan
`yamlresume templates list`:

```console
$ yamlresume templates list

| layouts.[].template | Engine | Template Name | Description                                                       |
| ------------------- | ------ | ------------- | --------------------------------------------------------------- |
| jake                | typst  | Jake's Resume | A simple, straight-forward resume template based on Jake's Resume |
```

Mesin Typst menggunakan `jake` secara bawaan. Pilih secara eksplisit dengan
`layouts.[].template`:

```yml lineNumbers title="resume.yml"
layouts:
  - engine: typst
    template: jake
```
