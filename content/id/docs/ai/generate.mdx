Perintah `yamlresume ai generate` menghasilkan file resume yang lengkap dan
realistis dari posisi dan bahasa target.

```console
$ yamlresume ai generate --help
Usage: yamlresume ai generate [options] <filename>

generate a new resume with AI

Arguments:
  filename                   output filename

Options:
  -p, --position <position>  target position or job title
  -l, --language <language>  target locale language
  -m, --model <model>        AI provider model to use
  -b, --base-url <url>       AI provider base URL
  -r, --retry <count>        maximum retries when validation fails (default: 2)
  -h, --help                 display help for command

Environment variables:

  Required (one API key for the selected cloud provider):
    DEEPSEEK_API_KEY          DeepSeek API key
    OPENAI_API_KEY            OpenAI API key
    MOONSHOT_API_KEY          Kimi (Moonshot AI) API key

  Optional:
    OLLAMA_HOST               Ollama host for local models
    YAMLRESUME_AI_MODEL       model override (overridden by --model)
    YAMLRESUME_AI_BASE_URL    API base URL override (overridden by --base-url)
```

## Penyedia yang Didukung

YAMLResume mendukung beberapa penyedia LLM melalui endpoint yang kompatibel
dengan OpenAI. Penyedia diinferens dari variabel lingkungan:

| Penyedia                                       | Variabel lingkungan yang diperlukan | Model bawaan      | Penimpaan opsional                              |
| ---------------------------------------------- | ----------------------------------- | ----------------- | ----------------------------------------------- |
| [DeepSeek](https://www.deepseek.com/)          | `DEEPSEEK_API_KEY`                  | `deepseek-v4-flash` | `YAMLRESUME_AI_MODEL`, `YAMLRESUME_AI_BASE_URL` |
| [Kimi](https://www.moonshot.cn/) (Moonshot AI) | `MOONSHOT_API_KEY`                  | `kimi-k2.6`       | `YAMLRESUME_AI_MODEL`, `YAMLRESUME_AI_BASE_URL` |
| [Ollama](https://ollama.com/) (lokal)          | `OLLAMA_HOST`                       | `llama3.2`        | `YAMLRESUME_AI_MODEL`, `YAMLRESUME_AI_BASE_URL` |
| [OpenAI](https://openai.com/)                  | `OPENAI_API_KEY`                    | `gpt-5`           | `YAMLRESUME_AI_MODEL`, `YAMLRESUME_AI_BASE_URL` |

## Contoh

Atur kunci API penyedia dan jalankan:

```console
$ export OPENAI_API_KEY=sk-...
$ yamlresume ai generate --position "Software Engineer" --language en resume.yml
```

Timpa model dan URL basis melalui flag CLI:

```console
$ yamlresume ai generate \
    --position "Registered Nurse" \
    --language en \
    --model gpt-5 \
    --base-url https://custom.openai.endpoint/v1 \
    resume.yml
```

Atau melalui variabel lingkungan:

```console
$ export YAMLRESUME_AI_MODEL=gpt-5
$ export YAMLRESUME_AI_BASE_URL=https://custom.openai.endpoint/v1
$ yamlresume ai generate --position "Registered Nurse" --language en resume.yml
```

### `--retry`

Hasil generasi divalidasi terhadap [skema
YAMLResume](/docs/compiler/schema) setelah setiap percobaan. Jika validasi
gagal, kesalahan diberikan kembali ke model dan pembuatan dicoba ulang. Jumlah
maksimum percobaan ulang adalah 2 secara default.

Anda dapat menyesuaikannya dengan opsi `-r, --retry`, yang menerima bilangan
bulat non-negatif. Misalnya, untuk mengizinkan hingga 5 kali percobaan ulang
untuk posisi yang sulit:

```console
$ yamlresume ai generate \
    --position "Software Engineer" \
    --language en \
    --retry 5 \
    resume.yml
```

Gunakan `--retry 0` untuk menonaktifkan percobaan ulang sepenuhnya, sehingga
langsung gagal pada kesalahan validasi pertama.

## Cara Kerja

`yamlresume ai generate` membangun prompt detail dari aturan [skema
YAMLResume](/docs/compiler/schema) dan contoh resume, kemudian meminta LLM
menghasilkan resume lengkap. Prompt menginstruksikan model untuk:

- Mengeluarkan hanya YAML yang valid, tanpa pembatas markdown.
- Menjaga komentar YAML sehingga file yang dihasilkan tetap mudah divalidasi
  oleh editor/IDE.
- Mengikuti semua batasan skema seperti panjang bidang, format tanggal, nilai
  enum, dan URL yang valid.
- Menciptakan konten orisinal dan realistis yang disesuaikan dengan posisi dan
  lokal target, tanpa menyalin detail pribadi dari contoh resume.

Teks yang dihasilkan kemudian diparsing dan divalidasi. Jika validasi gagal,
model diminta untuk memperbaiki kesalahan dan mencoba lagi, hingga batas
percobaan ulang yang dikonfigurasi.

## API Programatis

Paket [`@yamlresume/ai`](https://www.npmjs.com/package/@yamlresume/ai) juga
mengekspos API programatis untuk menghasilkan resume:

```ts
import { generateResume } from "@yamlresume/ai";
import { openai } from "@ai-sdk/openai";

const model = openai("gpt-5");

const yaml = await generateResume({
  position: "Software Engineer",
  language: "en",
  model,
});
```
