title: AI
---

YAMLResume menyediakan pembuatan resume berbasis AI melalui paket
[`@yamlresume/ai`](https://www.npmjs.com/package/@yamlresume/ai) dan perintah
CLI `yamlresume ai`.

## Ikhtisar

Kemampuan AI dibangun di atas [Vercel AI SDK](https://sdk.vercel.ai/) dan
mendukung beberapa penyedia LLM. Resume yang dihasilkan diparsing dan divalidasi
terhadap [skema YAMLResume](/docs/compiler/schema), dengan percobaan ulang
otomatis jika validasi gagal.

## Subperintah

```console
$ yamlresume ai --help
Usage: yamlresume ai [options] [command]

AI-powered resume generation

Options:
  -h, --help                     display help for command

Commands:
  generate [options] <filename>  generate a new resume with AI
  help [command]                 display help for command
```
