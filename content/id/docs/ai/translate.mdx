---
title: Terjemahkan
---

Perintah `yamlresume ai translate` menerjemahkan resume yang ada dari bahasa
lokalnya saat ini ke bahasa lain yang didukung tanpa mengubah struktur
YAMLResume.

```console
$ yamlresume ai translate --help
Usage: yamlresume ai translate [options] <input> <output>

translate a resume from one locale language to another with AI

Arguments:
  input                 source resume filename
  output                output resume filename

Options:
  -t, --to <language>   target locale language
  -m, --model <model>   AI provider model to use
  -b, --base-url <url>  AI provider base URL
  -r, --retry <count>   maximum retries when validation fails (default: 2)
  -h, --help            display help for command
```

## Contoh

Atur kunci API penyedia, lalu terjemahkan resume ke bahasa Mandarin Sederhana:

```console
$ export OPENAI_API_KEY=sk-...
$ yamlresume ai translate \
    --to zh-hans \
    resume.en.yml \
    resume.zh-hans.yml
```

Bahasa sumber dibaca dari kolom `locale.language` pada resume masukan. Perintah
ini memperbarui kolom tersebut ke bahasa tujuan dan menulis hasilnya ke jalur
keluaran. Berkas keluaran yang sudah ada tidak akan ditimpa.

Bahasa sumber dan tujuan harus berupa [bahasa lokal yang
didukung](/id/docs/locale): `de`, `en`, `es`, `fr`, `id`, `ja`, `nl`, `no`,
`pt-br`, `zh-hans`, `zh-hant-hk`, atau `zh-hant-tw`.

Model dan URL dasar dapat dipilih dengan `--model` dan `--base-url`, atau
melalui `YAMLRESUME_AI_MODEL` dan `YAMLRESUME_AI_BASE_URL`. Lihat
[Generate](./generate) untuk penyedia yang didukung dan variabel lingkungannya.

### `--retry`

Hasil terjemahan divalidasi terhadap [skema
YAMLResume](/id/docs/compiler/schema) setelah setiap percobaan. Jika validasi
gagal, kesalahan dikirim kembali ke model dan penerjemahan dicoba ulang. Batas
bawaan adalah 2 percobaan ulang.

```console
$ yamlresume ai translate \
    --to ja \
    --retry 5 \
    resume.en.yml \
    resume.ja.yml
```

Gunakan `--retry 0` untuk langsung gagal pada kesalahan validasi pertama tanpa
mencoba ulang.

## Konten yang diterjemahkan

Perintah ini menerjemahkan konten bahasa alami sambil mempertahankan struktur
dokumen sumber. Perintah ini:

- Mempertahankan kunci YAML, urutan daftar dan bagian, komentar, serta blok
  `layouts`.
- Memperbarui `locale.language` ke bahasa tujuan.
- Tidak mengubah URL, alamat email, nomor telepon, tanggal, dan kolom lokasi.
- Mempertahankan nilai enum skema dalam bahasa Inggris, seperti gelar,
  kefasihan, bahasa, tingkat keahlian, jaringan profil, dan negara.
- Tidak menambah atau menghapus bagian, item, maupun kolom.

Hasil diparsing dan divalidasi sebelum ditulis ke disk.

## API terprogram

Paket [`@yamlresume/ai`](https://www.npmjs.com/package/@yamlresume/ai) juga
menyediakan API penerjemahan:

```ts
import { translateResume } from "@yamlresume/ai";
import { openai } from "@ai-sdk/openai";

const model = openai("gpt-5");
const sourceYaml = "...";

const yaml = await translateResume(sourceYaml, "en", "zh-hans", {
  model,
});
```
