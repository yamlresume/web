title: Modelos
description: Escolha o modelo Typst Jake integrado e configure-o com `layouts[].template`.
---

Pode listar todos os modelos do YAMLResume, incluindo os modelos Typst, com
`yamlresume templates list`:

```console
$ yamlresume templates list

| layouts.[].template | Engine | Template Name | Description                                                       |
| ------------------- | ------ | ------------- | --------------------------------------------------------------- |
| jake                | typst  | Jake's Resume | A simple, straight-forward resume template based on Jake's Resume |
```

O motor Typst usa o `jake` por predefinição. Selecione-o explicitamente com
`layouts.[].template`:

```yml lineNumbers title="resume.yml"
layouts:
  - engine: typst
    template: jake
```
