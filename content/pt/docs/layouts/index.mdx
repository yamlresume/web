title: Layouts
description: "Configure um ou mais layouts por currículo — LaTeX, Typst, HTML, DOCX e Markdown —, cada um com seu motor, template e opções de estilo."
---

O núcleo de um currículo é o conteúdo, mas o design também é importante. Muitos geradores de currículo baseados em JSON/YAML concentram-se apenas no conteúdo, deixando o design intacto, o que representa um grande problema para o utilizador.

Ao contrário de outros geradores de currículo, o YAMLResume fornece uma solução de design pronta a usar, que permite aos utilizadores concentrar-se no conteúdo do currículo enquanto geram currículos de aspeto profissional com uma composição tipográfica perfeita em píxeis.

A partir da v0.8.0, o YAMLResume suporta múltiplos layouts e vários motores de saída (LaTeX, Markdown, HTML e DOCX) através da matriz `layouts`.

Aqui está um exemplo de configuração de layout num ficheiro `resume.yml`:

```yml lineNumbers title="resume.yml"
---
content:
  # ...

locale:
  language: en

layouts:
  - engine: latex
    template: moderncv-banking
    page:
      showPageNumbers: true
      margins:
        top: 2.5cm
        left: 1.5cm
        right: 1.5cm
        bottom: 2.5cm
    typography:
      fontSize: 11pt
  - engine: markdown
```

## Motores

O YAMLResume suporta atualmente cinco motores:

- [HTML](./layouts/html): Gera currículos HTML nativos da web.
- [LaTeX](./layouts/latex): Gera currículos em PDF de alta qualidade com LaTeX.
- [Typst](./layouts/typst): Gera currículos em PDF de alta qualidade com Typst.
- [Markdown](./layouts/markdown): Gera currículos em Markdown simples.
- [DOCX](./layouts/docx): Gera documentos Microsoft Word.
