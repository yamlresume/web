O YAMLResume fornece pacotes e ferramentas reutilizáveis para construir fluxos de trabalho de currículos, incorporar editores, automatizar construções, gerir exemplos e converter dados de currículos existentes.

## @yamlresume/node

O [`@yamlresume/node`](./ecosystem/node) é o runtime Node.js reutilizável por trás do CLI do YAMLResume.

- Lê e valida ficheiros de currículo YAML, YML ou JSON com erros posicionais.
- Constrói layouts configurados, monitoriza ficheiros e compila PDFs de LaTeX ou Typst.
- Cria currículos a partir de exemplos ou gera e traduz ficheiros com IA.

## @yamlresume/playground

O [`@yamlresume/playground`](./ecosystem/playground) é o componente React por trás do [playground](/pt/playground) oficial.

- Incorpora um editor Monaco YAML consciente do esquema e uma pré-visualização multi-layout ao vivo.
- Usa layouts responsivos de desktop e mobile, ações de exportação e rótulos de UI localizados.
- Integra-se com Vite, Next.js, Tailwind CSS e configurações personalizadas de workers do Monaco.

## create-yamlresume

O [create-yamlresume](./ecosystem/create-yamlresume) facilita iniciar um novo
projeto de YAMLResume com um comando de uma linha. Irá estruturar o diretório
do teu projeto, instalar as dependências necessárias e gerar um arquivo de
currículo de exemplo para que possas começar de imediato.

- Estrutura um novo projeto com `npx create-yamlresume my-resume` ou comandos
  similares para `npm`, `yarn`, ou `pnpm`.
- Inclui uma estrutura de projeto pronta a usar, scripts para construir e
  validar currículos, e um arquivo de currículo YAML de exemplo.

## json2yamlresume

O [json2yamlresume](./ecosystem/json2yamlresume) é uma ferramenta CLI para
converter arquivos de [JSON Resume](https://jsonresume.org/) para o formato
YAMLResume.

- Converte ficheiros JSON Resume para YAMLResume, transformando campos e
  estrutura conforme necessário.
- Garante que os teus dados são validados contra o esquema do YAMLResume.

Estas ferramentas ajudam-te a migrar de outros formatos, automatizar a
configuração do projeto e otimizar o teu fluxo de trabalho com YAMLResume.

## samples

O [`@yamlresume/samples`](./ecosystem/samples) fornece um catálogo de
currículos de exemplo curados para posições comuns, cada um traduzido em 12
idiomas locais.

- Alimenta o comando `yamlresume new --sample` e o subcomando
  `yamlresume samples list`.
- Expõe APIs de consulta para filtrar currículos de exemplo por idioma,
  categoria ou tag.
