O italiano é uma língua românica escrita com o alfabeto latino. O YAMLResume
suporta currículos em italiano com `locale.language: it`, traduzindo termos
fixos de secção, graus de educação, nomes de idiomas, níveis de fluência e
nomes de países.

```yml lineNumbers title="resume.it.yml"
content:
  # ...

locale:
  language: it
```

## Linguística

### Conjunto de Caracteres

O italiano usa o alfabeto latino de 21 letras. Vogais acentuadas como `à`, `è`,
`é`, `ì`, `ò` e `ù` são comuns, e as fontes Unicode padrão, como a Linux
Libertine, cobrem-nas sem configuração adicional.

### Capitalização

O italiano usa menos maiúsculas do que o inglês em datas, graus e muitos termos
fixos. O YAMLResume segue a capitalização italiana nas suas traduções
integradas, em vez de preservar a forma inglesa.

## Modismos

### Data

Os nomes dos meses são escritos em minúsculas nos currículos italianos. O
YAMLResume localiza as datas para as seguintes formas:

| Inglês          | Italiano           |
| --------------- | ------------------ |
| January (Jan)   | gennaio (gen)      |
| February (Feb)  | febbraio (feb)     |
| March (Mar)     | marzo (mar)        |
| April (Apr)     | aprile (apr)       |
| May (May)       | maggio (mag)       |
| June (Jun)      | giugno (giu)       |
| July (Jul)      | luglio (lug)       |
| August (Aug)    | agosto (ago)       |
| September (Sep) | settembre (set)    |
| October (Oct)   | ottobre (ott)      |
| November (Nov)  | novembre (nov)     |
| December (Dec)  | dicembre (dic)     |

### Pontuação e Números

O italiano normalmente usa uma vírgula como separador decimal e um ponto como
separador de milhares. A pontuação de citações e listas segue as convenções
italianas padrão, enquanto o YAMLResume mantém os URLs, os endereços de e-mail e
os valores do esquema na sua forma original.
