## ワークフローと自動化

YAMLResume のコマンドを手で叩かずに履歴書をビルド・公開する方法です。

- [wldyslw/resume](https://github.com/wldyslw/resume) — Makefile と Docker による自動化。
- [anakinkinsey/resume](https://github.com/anakinkinsey/resume) — 公式 Docker イメージでコマンド 1 つでビルド。
- [conorwithonen/resume](https://github.com/conorwithonen/resume) — Docker と Task で管理する DevOps エンジニアの履歴書。
- [linxing/resume2](https://github.com/linxing/resume2) — YAMLResume と GitHub Actions。
- [mfyz/mfyz-resume](https://github.com/mfyz/mfyz-resume) — YAMLResume を基盤にした個人用履歴書ツールキット。

## AI とエージェントツール

YAMLResume ファイルを生成または利用する、履歴書カスタマイズエージェントと LLM 統合です。

- [zhiweio/resume-as-code](https://github.com/zhiweio/resume-as-code) — 構造化データからカスタマイズされた履歴書を生成する LLM 駆動パイプライン。
- [AnxForever/yamlresume](https://github.com/AnxForever/yamlresume) — 根拠に基づくカスタマイズエージェント。生成されたすべての記述は候補者自身の資料に遡れます。
- [oat431/job-hunting-loop](https://github.com/oat431/job-hunting-loop) — YAMLResume を基盤にした求職ループ。
- [JoeMattie/job-hunt-kit](https://github.com/JoeMattie/job-hunt-kit) — 求職ツールキット。
- [Remi-Z/resume-composer-gpt](https://github.com/Remi-Z/resume-composer-gpt) — 履歴書、CV、カバーレター用のローカル Codex プラグイン。
- [downquark7/resume-builder](https://github.com/downquark7/resume-builder) — YAMLResume 互換の YAML を出力し、CLI で PDF を生成する AI 履歴書ビルダー。

## エディタと管理ツール

- [Li7777777/resume-manager](https://github.com/Li7777777/resume-manager) — タグ付き YAML から異なる履歴書を組み立てるビジュアル履歴書マネージャー。ビルドワークフローのテンプレートも同梱されています。
