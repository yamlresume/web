title: AI

YAMLResume は、[`@yamlresume/ai`](https://www.npmjs.com/package/@yamlresume/ai)
パッケージと `yamlresume ai` CLI コマンドを通じて、AI による履歴書生成機能を提供しています。

## 概要

AI 機能は [Vercel AI SDK](https://sdk.vercel.ai/) を基盤として構築されており、複数の LLM プロバイダーをサポートしています。生成された履歴書は
[YAMLResume スキーマ](/docs/compiler/schema) に対して解析・検証され、検証に失敗した場合は自動的に再試行されます。

## サブコマンド

```console
$ yamlresume ai --help
Usage: yamlresume ai [options] [command]

AI-powered resume generation

Options:
  -h, --help                     display help for command

Commands:
  generate [options] <filename>  generate a new resume with AI
  help [command]                 display help for command
```
