---
title: テンプレート
description: 組み込みの Typst Jake テンプレートを選択し、`layouts[].template` で設定します。
---

`yamlresume templates list` を使用すると、Typst テンプレートを含むすべての
YAMLResume テンプレートを一覧表示できます：

```console
$ yamlresume templates list

| layouts.[].template | Engine | Template Name | Description                                                       |
| ------------------- | ------ | ------------- | --------------------------------------------------------------- |
| jake                | typst  | Jake's Resume | A simple, straight-forward resume template based on Jake's Resume |
```

Typst エンジンはデフォルトで `jake` を使用します。`layouts.[].template` で明示的に
選択することもできます：

```yml lineNumbers title="resume.yml"
layouts:
  - engine: typst
    template: jake
```
