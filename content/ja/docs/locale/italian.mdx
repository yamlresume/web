イタリア語はラテン文字で書かれるロマンス語です。YAMLResume は
`locale.language: it` を指定することでイタリア語の履歴書をサポートし、固定のセク
ション用語、学位、言語名、流暢さレベル、国名を翻訳します。

```yml lineNumbers title="resume.it.yml"
content:
  # ...

locale:
  language: it
```

## 言語学

### 文字セット

イタリア語は21文字のラテン文字を使用します。`à`、`è`、`é`、`ì`、`ò`、`ù` などのア
クセント付き母音がよく使われますが、Linux Libertine のような標準的な Unicode フォ
ントであれば追加設定なしで表示できます。

### 大文字の使用

イタリア語では、日付、学位、多くの固定用語において英語ほど大文字を使用しません。
YAMLResume の組み込み翻訳は英語の表記をそのまま残すのではなく、イタリア語の大文字・
小文字の慣習に従います。

## 慣用句

### 日付

イタリア語の履歴書では、月の名前は小文字で書きます。YAMLResume は日付を以下の形式に
ローカライズします：

| 英語            | イタリア語      |
| --------------- | --------------- |
| January (Jan)   | gennaio (gen)   |
| February (Feb)  | febbraio (feb)  |
| March (Mar)     | marzo (mar)     |
| April (Apr)     | aprile (apr)    |
| May (May)       | maggio (mag)    |
| June (Jun)      | giugno (giu)    |
| July (Jul)      | luglio (lug)    |
| August (Aug)    | agosto (ago)    |
| September (Sep) | settembre (set) |
| October (Oct)   | ottobre (ott)   |
| November (Nov)  | novembre (nov)  |
| December (Dec)  | dicembre (dic)  |

### 句読点と数字

イタリア語では通常、小数点としてカンマを、桁区切りとしてピリオドを使用します。引用
符やリストの句読点は標準的なイタリア語の慣習に従いますが、YAMLResume は URL、メール
アドレス、スキーマの値を元の形式のまま保持します。

## サンプル履歴書

20 個の厳選されたサンプルはすべてイタリア語で利用できます。CLI で作成できます：

```console
$ yamlresume new resume.it.yml --sample software-engineer --language it
```

LaTeX、Typst、HTML、DOCX、Markdown でレンダリングされた例は
[イタリア語ギャラリー](/ja/gallery/languages/it) でご覧ください。
