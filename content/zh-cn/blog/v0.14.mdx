我们很高兴地宣布 [YAMLResume
v0.14](https://github.com/yamlresume/yamlresume/releases/tag/v0.14.0) 正式发布。
此版本为 YAMLResume 带来了 [AI 驱动的简历生成](/zh-cn/docs/ai) 功能，包含全新的
[`yamlresume ai generate`](/zh-cn/docs/ai/generate) 指令、`@yamlresume/ai` 包、对多个
LLM 提供商的支持，以及惯例的错误修复和改进。

TL:DR，演示：

[![YAMLResume ai generate 演示](https://asciinema.org/a/1262687.svg)](https://asciinema.org/a/1262687)

## 新包：@yamlresume/ai

此版本的核心是全新的
[`@yamlresume/ai`](https://www.npmjs.com/package/@yamlresume/ai) 包。它为
YAMLResume 提供 AI 驱动的生成能力，并构建在 [Vercel AI SDK](https://sdk.vercel.ai/)
之上。

此包提供了一个简洁的程序化 API 来生成简历：

```ts
import { generateResume } from "@yamlresume/ai";
import { openai } from "@ai-sdk/openai";

const model = openai("gpt-5");

const yaml = await generateResume({
  position: "Software Engineer",
  language: "en",
  model,
});
```

生成的输出会根据 `@yamlresume/core` 的 [YAMLResume schema](https://yamlresume.dev/docs/compiler/schema) 进行解析与验证。如果验证失败，
系统会自动重试（默认最多 2 次），并将先前的错误反馈给模型，因此你得到的是有效的简历 YAML，
而不是破碎的草稿。

## 新指令：yamlresume ai generate

此版本的头号功能是全新的 `yamlresume ai generate` 指令，它能将职位和语言转换为一份完整、
真实的简历文件。

### 支持的提供商

YAMLResume 通过 OpenAI 兼容端点支持多个 LLM 提供商。提供商会从环境变量中自动推断：

| Provider                                       | Required env variable | Default model       | Optional overrides                              |
| ---------------------------------------------- | --------------------- | ------------------- | ----------------------------------------------- |
| [DeepSeek](https://www.deepseek.com/)          | `DEEPSEEK_API_KEY`    | `deepseek-v4-flash` | `YAMLRESUME_AI_MODEL`, `YAMLRESUME_AI_BASE_URL` |
| [Kimi](https://www.moonshot.cn/) (Moonshot AI) | `MOONSHOT_API_KEY`    | `kimi-k2.6`         | `YAMLRESUME_AI_MODEL`, `YAMLRESUME_AI_BASE_URL` |
| [Ollama](https://ollama.com/) (local)          | `OLLAMA_HOST`         | `llama3.2`          | `YAMLRESUME_AI_MODEL`, `YAMLRESUME_AI_BASE_URL` |
| [OpenAI](https://openai.com/)                  | `OPENAI_API_KEY`      | `gpt-5`             | `YAMLRESUME_AI_MODEL`, `YAMLRESUME_AI_BASE_URL` |

提供商会按照上表顺序进行检测。当未检测到任何提供商时，会使用 Kimi 作为默认值，以便在缺少 API
key 时产生明确的配置错误信息。

### 生成你的第一份简历

设置提供商 API key 后，运行：

```console
$ export OPENAI_API_KEY=sk-...
$ yamlresume ai generate --position "Software Engineer" --language en resume.yml
```

此指令会在 `resume.yml` 生成一份完整的简历文件，包含 basics、location、profiles、
education、work、skills、languages 等区段，以及根据职位量身打造的相关可选区段。

### 覆盖模型与基础 URL

你可以通过环境变量或 CLI 标志来覆盖模型和基础 URL。CLI 标志的优先级高于环境变量。

```console
$ yamlresume ai generate \
    --position "Registered Nurse" \
    --language en \
    --model gpt-5 \
    --base-url https://custom.openai.endpoint/v1 \
    resume.yml
```

或者：

```console
$ export YAMLRESUME_AI_MODEL=gpt-5
$ export YAMLRESUME_AI_BASE_URL=https://custom.openai.endpoint/v1
$ yamlresume ai generate --position "Registered Nurse" --language en resume.yml
```

运行 `yamlresume ai generate --help` 以查看所有可用的选项和环境变量。

## 运作方式

`yamlresume ai generate` 会从 [YAMLResume schema](https://yamlresume.dev/docs/compiler/schema) 规则和一份示例简历构建详细的 prompt，
然后要求 LLM 产出一份完整简历。此 prompt 会指示模型：

- 只输出有效的 YAML，不要加上 markdown 围栏。
- 保留 YAML 注释，让生成的文件对编辑器/IDE 验证更友好。
- 遵守所有 schema 限制，例如字段长度、日期格式、枚举值和有效 URL。
- 发明原创且真实的内容，并根据目标职位与地区进行调整，但不复制示例简历的个人信息。

生成的文字接着会被解析并验证。如果验证失败，模型会被要求修正错误并重试，最多到设定的重试上限。

## 错误修复与改进

### 自 v0.13.0 以来的修补版本

在 v0.13.0 与 v0.14.0 之间，我们发布了两个修补版本，包含多项改进：

**v0.13.2**

- 将 [DOCX 引擎](/zh-cn/docs/layouts/docx) 加入 `yamlresume new` 默认生成的布局中
- 将 `Discord` 加入支持的社交网络选项
- 将项目描述的最大长度从 128 个字符延长至 1024 个字符
- 为 HTML 区段元素新增 `id` 属性以支持锚点导航
- 将 `education.startDate` 设为可选

**v0.13.1**

- 修复 playground 工具栏高度与 DOCX 内容滚动行为
- 关闭浏览器控制台中恼人的 `localStorage` 警告

### v0.14.0 修复

### HTML Calm 模板技能布局

- HTML Calm 模板中的技能在使用关键词时现在会垂直堆叠，以改善窄视窗下的可读性。感谢
  [couimet](https://github.com/couimet) 的
  [PR](https://github.com/yamlresume/yamlresume/pull/248)。
