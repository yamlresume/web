我们很高兴地宣布 [YAMLResume v0.16](https://github.com/yamlresume/yamlresume/releases/tag/v0.16.0) 正式发布。此版本通过新的 [`yamlresume ai translate`](/zh-cn/docs/ai/translate) 命令和 [`@yamlresume/ai`](https://www.npmjs.com/package/@yamlresume/ai) 中的 `translateResume` API，带来了 AI 简历翻译功能。

## 新命令：yamlresume ai translate

指定输入文件、输出文件和目标区域语言：

```console
$ export OPENAI_API_KEY=sk-...
$ yamlresume ai translate \
    --to zh-hans \
    resume.en.yml \
    resume.zh-hans.yml
```

源语言从 `locale.language` 读取。翻译结果会更新该字段并保存到新文件中，不会覆盖已有的输出文件。

该命令支持 YAMLResume 的全部 12 种区域语言：`de`、`en`、`es`、`fr`、`id`、`ja`、`nl`、`no`、`pt-br`、`zh-hans`、`zh-hant-hk` 和 `zh-hant-tw`。

## 保留结构的翻译

命令会翻译自然语言内容，同时保留 YAML 键、列表和章节顺序、注释及 `layouts` 块。URL、电子邮箱、电话号码、日期、地址和 schema 枚举值也不会被修改。

结果在写入磁盘前会进行解析，并根据 [YAMLResume schema](/zh-cn/docs/compiler/schema) 进行验证。

## 自动验证与重试

如果验证失败，错误会反馈给模型并重新翻译。默认最多重试 2 次，可通过 `--retry` 修改：

```console
$ yamlresume ai translate \
    --to ja \
    --retry 5 \
    resume.en.yml \
    resume.ja.yml
```

使用 `--retry 0` 可禁用重试。服务提供商、模型和基础 URL 配置与 [`yamlresume ai generate`](/zh-cn/docs/ai/generate) 相同。

## 编程 API

```ts
import { translateResume } from "@yamlresume/ai";
import { openai } from "@ai-sdk/openai";

const model = openai("gpt-5");
const sourceYaml = "...";

const yaml = await translateResume(sourceYaml, "en", "zh-hans", {
  model,
});
```

对于基于文件的 Node.js 工作流，`@yamlresume/node` 还提供了 `translateResumeFile`。
