YAMLResume 提供了一套可复用的包和工具，用于构建简历工作流、嵌入编辑器、自动化构建、管理示例简历以及转换现有的简历数据。

## @yamlresume/node

[`@yamlresume/node`](./ecosystem/node) 是 YAMLResume CLI 背后的可复用 Node.js 运行时。

- 读取并验证 YAML、YML 或 JSON 简历文件，并提供带位置的错误信息。
- 构建已配置的布局、监视文件，并编译 LaTeX 或 Typst PDF。
- 从示例创建简历，或使用 AI 生成和翻译文件。

## @yamlresume/playground

[`@yamlresume/playground`](./ecosystem/playground) 是官方[游乐场](/zh-cn/playground)背后的 React 组件。

- 嵌入架构感知的 Monaco YAML 编辑器和实时多布局预览。
- 使用响应式的桌面和移动端布局、导出操作和本地化 UI 标签。
- 与 Vite、Next.js、Tailwind CSS 以及自定义 Monaco worker 配置集成。

## create-yamlresume

[create-yamlresume](./ecosystem/create-yamlresume) 让您可以通过一行命令轻松启动新的 YAMLResume 项目。它将搭建您的项目目录，安装必要的依赖，并生成示例简历文件，这样您就可以立即开始。

- 使用 `npx create-yamlresume my-resume` 或类似的 `npm`、`yarn` 或 `pnpm` 命令搭建新项目。
- 包括即用型项目结构、用于构建和验证简历的脚本，以及示例 YAML 简历文件。

## json2yamlresume

[json2yamlresume](./ecosystem/json2yamlresume) 是一个用于将 [JSON Resume](https://jsonresume.org/) 文件转换为 YAMLResume 格式的 CLI 工具。

- 将 JSON Resume 文件转换为 YAMLResume，根据需要转换字段和结构。
- 确保您的数据根据 YAMLResume 模式进行验证。

这些工具帮助您从其他格式迁移，自动化项目设置，并简化您与 YAMLResume 的工作流程。

## samples

[`@yamlresume/samples`](./ecosystem/samples) 提供了一份针对常见职位的精选示例简历目录，每种示例都翻译成了 12 种区域语言。

- 为 `yamlresume new --sample` 命令和 `yamlresume samples` list 子命令提供支持。
- 暴露查询 API，可以按语言、类别或标签筛选示例简历。
