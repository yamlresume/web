## 工作流与自动化

不手动敲 YAMLResume 命令，也能构建和发布简历的各种方式。

- [wldyslw/resume](https://github.com/wldyslw/resume) — 用 Makefile 和 Docker
  实现自动化。
- [anakinkinsey/resume](https://github.com/anakinkinsey/resume) — 一条命令即可用官方
  Docker 镜像完成构建。
- [conorwithonen/resume](https://github.com/conorwithonen/resume) — 用 Docker 和
  Task 管理一位 DevOps 工程师的简历。
- [linxing/resume2](https://github.com/linxing/resume2) — YAMLResume 加
  GitHub Actions。
- [mfyz/mfyz-resume](https://github.com/mfyz/mfyz-resume) — 基于 YAMLResume
  的个人简历工具集。

## AI 与 Agent 工具

能够生成或消费 YAMLResume 文件的简历定制 Agent 与 LLM 集成。

- [zhiweio/resume-as-code](https://github.com/zhiweio/resume-as-code) —
  由 LLM 驱动的流水线，把结构化数据变成定制化简历。
- [AnxForever/yamlresume](https://github.com/AnxForever/yamlresume) —
  有据可依的定制 Agent：每一条生成的表述都能回溯到候选人自己的材料。
- [oat431/job-hunting-loop](https://github.com/oat431/job-hunting-loop) — 基于
  YAMLResume 的求职循环。
- [JoeMattie/job-hunt-kit](https://github.com/JoeMattie/job-hunt-kit) —
  求职工具集。
- [Remi-Z/resume-composer-gpt](https://github.com/Remi-Z/resume-composer-gpt) —
  本地 Codex 插件，用于生成简历、CV 和求职信。
- [downquark7/resume-builder](https://github.com/downquark7/resume-builder) —
  AI 简历生成器，输出兼容 YAMLResume 的 YAML，并调用 CLI 生成 PDF。

## 编辑器与管理工具

- [Li7777777/resume-manager](https://github.com/Li7777777/resume-manager) —
  可视化简历管理器，从带标签的 YAML 组合出不同的简历，并附带构建工作流模板。
