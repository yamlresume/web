---
title: 模板
description: 选择内置 Typst Jake 模板，并通过 `layouts[].template` 进行配置。
---

运行 `yamlresume templates list` 可以列出包括 Typst 在内的全部 YAMLResume 模板：

```console
$ yamlresume templates list

| layouts.[].template | Engine | Template Name | Description                                                       |
| ------------------- | ------ | ------------- | --------------------------------------------------------------- |
| jake                | typst  | Jake's Resume | A simple, straight-forward resume template based on Jake's Resume |
```

Typst 引擎默认使用 `jake`。你也可以通过 `layouts.[].template` 显式选择：

```yml lineNumbers title="resume.yml"
layouts:
  - engine: typst
    template: jake
```
