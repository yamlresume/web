---
title: 範本
description: 選擇內建 Typst Jake 範本，並透過 `layouts[].template` 進行配置。
---

執行 `yamlresume templates list` 可以列出包括 Typst 在內的全部 YAMLResume 範本：

```console
$ yamlresume templates list

| layouts.[].template | Engine | Template Name | Description                                                       |
| ------------------- | ------ | ------------- | --------------------------------------------------------------- |
| jake                | typst  | Jake's Resume | A simple, straight-forward resume template based on Jake's Resume |
```

Typst 引擎預設使用 `jake`。你也可以透過 `layouts.[].template` 明確選擇：

```yml lineNumbers title="resume.yml"
layouts:
  - engine: typst
    template: jake
```
