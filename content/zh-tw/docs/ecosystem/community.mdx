## 工作流程與自動化

不必手動輸入 YAMLResume 指令，也能建置與發佈履歷的各種方式。

- [wldyslw/resume](https://github.com/wldyslw/resume) — 以 Makefile 與 Docker
  實現自動化。
- [anakinkinsey/resume](https://github.com/anakinkinsey/resume) — 一個指令即可用官方
  Docker 映像完成建置。
- [conorwithonen/resume](https://github.com/conorwithonen/resume) — 以 Docker 與
  Task 管理一位 DevOps 工程師的履歷。
- [linxing/resume2](https://github.com/linxing/resume2) — YAMLResume 加上
  GitHub Actions。
- [mfyz/mfyz-resume](https://github.com/mfyz/mfyz-resume) — 以 YAMLResume
  為基礎的個人履歷工具組。

## AI 與 Agent 工具

能夠產生或消費 YAMLResume 檔案的履歷客製化 Agent 與 LLM 整合。

- [zhiweio/resume-as-code](https://github.com/zhiweio/resume-as-code) —
  由 LLM 驅動的流程，把結構化資料變成客製化履歷。
- [AnxForever/yamlresume](https://github.com/AnxForever/yamlresume) —
  有憑有據的客製化 Agent：每一條產生的陳述都能回溯到求職者自己的素材。
- [oat431/job-hunting-loop](https://github.com/oat431/job-hunting-loop) — 以
  YAMLResume 為基礎的求職循環。
- [JoeMattie/job-hunt-kit](https://github.com/JoeMattie/job-hunt-kit) —
  求職工具組。
- [Remi-Z/resume-composer-gpt](https://github.com/Remi-Z/resume-composer-gpt) —
  本機 Codex 外掛，用於產生履歷、CV 與求職信。
- [downquark7/resume-builder](https://github.com/downquark7/resume-builder) —
  AI 履歷產生器，輸出相容於 YAMLResume 的 YAML，並呼叫 CLI 產生 PDF。

## 編輯器與管理工具

- [Li7777777/resume-manager](https://github.com/Li7777777/resume-manager) —
  視覺化履歷管理器，從帶標籤的 YAML 組合成不同的履歷，並附帶建置工作流程範本。
