---
title: AI
---

YAMLResume 透過 [`@yamlresume/ai`](https://www.npmjs.com/package/@yamlresume/ai)
套件和 `yamlresume ai` CLI 指令提供 AI 驅動的履歷生成功能。

## 概述

AI 功能建構於 [Vercel AI SDK](https://sdk.vercel.ai/) 之上，支援多個 LLM
提供者。生成的履歷會針對 [YAMLResume
schema](/docs/compiler/schema) 進行解析與驗證，若驗證失敗會自動重試。

## 子命令

```console
$ yamlresume ai --help
Usage: yamlresume ai [options] [command]

AI-powered resume generation

Options:
  -h, --help                     display help for command

Commands:
  generate [options] <filename>  generate a new resume with AI
  help [command]                 display help for command
```
