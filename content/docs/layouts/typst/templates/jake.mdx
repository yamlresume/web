Jake is a clean and professional resume template inspired by
[jakegut/resume](https://github.com/jakegut/resume). The Typst implementation
ports the focused, single-column design of the [LaTeX Jake
template](/docs/layouts/latex/templates/jake) while using the same localized
terms, Markdown summaries and structured content as every YAMLResume engine.

```yml lineNumbers title="resume.yml"
layouts:
  - engine: typst
    template: jake
    theme:
      colors:
        accent: black
    typography:
      fontSize: 10pt
      links:
        underline: false
```

The template supports configurable page margins, font families, line spacing,
accent colors, section aliases and ordering. Its CJK font fallbacks select
fonts appropriate to the resume locale.
