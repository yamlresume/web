---
title: Templates
description: Choose the built-in Typst Jake template and configure it with `layouts[].template`.
---

You can list every YAMLResume template, including the Typst templates, with
`yamlresume templates list`:

```console
$ yamlresume templates list

| layouts.[].template | Engine | Template Name | Description                                                       |
| ------------------- | ------ | ------------- | --------------------------------------------------------------- |
| jake                | typst  | Jake's Resume | A simple, straight-forward resume template based on Jake's Resume |
```

The Typst engine uses `jake` by default. Select it explicitly with
`layouts.[].template`:

```yml lineNumbers title="resume.yml"
layouts:
  - engine: typst
    template: jake
```
