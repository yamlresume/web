YAMLResume is used by people around the world to build and ship their resumes.
This page collects the ones we know about: resumes maintained as YAML in public
repositories, and the workflows and tools people have built around the CLI.

Found something missing? [Add yours](#add-yours).

## Workflows and automation

Ways people build and publish resumes without touching YAMLResume by hand.

- [wldyslw/resume](https://github.com/wldyslw/resume) — Makefile and Docker
  automation.
- [anakinkinsey/resume](https://github.com/anakinkinsey/resume) — builds with
  the official Docker image in a single command.
- [conorwithonen/resume](https://github.com/conorwithonen/resume) — Docker and
  Task for a DevOps engineer's resume.
- [linxing/resume2](https://github.com/linxing/resume2) — YAMLResume plus
  GitHub Actions.
- [mfyz/mfyz-resume](https://github.com/mfyz/mfyz-resume) — a personal resume
  toolkit built on YAMLResume.

## AI and agent tooling

Resume tailoring agents and LLM integrations that emit or consume YAMLResume
files.

- [zhiweio/resume-as-code](https://github.com/zhiweio/resume-as-code) —
  LLM-driven pipeline that turns structured data into tailored resumes.
- [AnxForever/yamlresume](https://github.com/AnxForever/yamlresume) —
  evidence-backed tailoring agent: every generated claim points back at the
  candidate's own material.
- [oat431/job-hunting-loop](https://github.com/oat431/job-hunting-loop) — a job
  hunt loop built on YAMLResume.
- [JoeMattie/job-hunt-kit](https://github.com/JoeMattie/job-hunt-kit) — a job
  hunt kit.
- [Remi-Z/resume-composer-gpt](https://github.com/Remi-Z/resume-composer-gpt) —
  a local Codex plugin for resumes, CVs, and cover letters.
- [downquark7/resume-builder](https://github.com/downquark7/resume-builder) — an
  AI resume builder that emits YAMLResume-compatible YAML and calls the CLI for
  PDF output.

## Editors and managers
