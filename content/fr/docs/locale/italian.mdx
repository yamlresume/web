L'italien est une langue romane écrite avec l'alphabet latin. YAMLResume prend
en charge les CV italiens avec `locale.language: it`, en traduisant les termes
fixes des sections, les diplômes, les noms de langues, les niveaux de compétence
linguistique et les noms de pays.

```yml lineNumbers title="resume.it.yml"
content:
  # ...

locale:
  language: it
```

## Linguistique

### Jeu de Caractères

L'italien utilise l'alphabet latin de 21 lettres. Les voyelles accentuées comme
`à`, `è`, `é`, `ì`, `ò` et `ù` sont courantes, et les polices Unicode standard
telles que Linux Libertine les prennent en charge sans configuration
supplémentaire.

### Majuscules

L'italien utilise moins de majuscules que l'anglais pour les dates, les diplômes
et de nombreux termes fixes. YAMLResume suit la casse italienne dans ses
traductions intégrées plutôt que de conserver la forme anglaise.

## Idiomes

### Date

Les noms de mois sont en minuscules dans les CV italiens. YAMLResume localise
les dates selon les formes suivantes :

| Anglais         | Italien            |
| --------------- | ------------------ |
| January (Jan)   | gennaio (gen)      |
| February (Feb)  | febbraio (feb)     |
| March (Mar)     | marzo (mar)        |
| April (Apr)     | aprile (apr)       |
| May (May)       | maggio (mag)       |
| June (Jun)      | giugno (giu)       |
| July (Jul)      | luglio (lug)       |
| August (Aug)    | agosto (ago)       |
| September (Sep) | settembre (set)    |
| October (Oct)   | ottobre (ott)      |
| November (Nov)  | novembre (nov)     |
| December (Dec)  | dicembre (dic)     |

### Ponctuation et Nombres

L'italien utilise normalement une virgule comme séparateur décimal et un point
comme séparateur de milliers. La ponctuation des guillemets et des listes suit
les conventions italiennes standard, tandis que YAMLResume conserve les URL, les
adresses e-mail et les valeurs du schéma sous leur forme d'origine.
