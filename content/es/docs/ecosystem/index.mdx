title: Ecosistema
---

YAMLResume proporciona paquetes y herramientas reutilizables para construir flujos de trabajo de currículums, incrustar editores, automatizar construcciones, gestionar ejemplos y convertir datos de currículums existentes.

## @yamlresume/node

[`@yamlresume/node`](./ecosystem/node) es el runtime de Node.js reutilizable detrás del CLI de YAMLResume.

- Lee y valida archivos de currículum YAML, YML o JSON con errores posicionales.
- Construye diseños configurados, vigila archivos y compila PDFs de LaTeX o Typst.
- Crea currículums a partir de ejemplos o genera y traduce archivos con IA.

## @yamlresume/playground

[`@yamlresume/playground`](./ecosystem/playground) es el componente React detrás de la [zona de pruebas](/es/playground) oficial.

- Incrusta un editor Monaco YAML con soporte de esquema y una vista previa multi-diseño en vivo.
- Usa diseños responsivos de escritorio y móvil, acciones de exportación y etiquetas de UI localizadas.
- Intégralo con Vite, Next.js, Tailwind CSS y configuraciones personalizadas de workers de Monaco.

## create-yamlresume

[create-yamlresume](./ecosystem/create-yamlresume) facilita iniciar un nuevo
proyecto de YAMLResume con un comando de una sola línea. Estructurará el
directorio de tu proyecto, instalará las dependencias necesarias y generará un
archivo de currículum de muestra para que puedas comenzar de inmediato.

- Estructura un nuevo proyecto con `npx create-yamlresume my-resume` o comandos
  similares para `npm`, `yarn`, o `pnpm`.
- Incluye una estructura de proyecto lista para usar, scripts para construir y
  validar currículums, y un archivo de currículum YAML de muestra.

## json2yamlresume

[json2yamlresume](./ecosystem/json2yamlresume) es una herramienta CLI para
convertir archivos de [JSON Resume](https://jsonresume.org/) al formato
YAMLResume.

- Convierte archivos JSON Resume a YAMLResume, transformando campos y estructura
  según sea necesario.
- Asegura que tus datos sean validados contra el esquema de YAMLResume.

Estas herramientas te ayudan a migrar desde otros formatos, automatizar la
configuración del proyecto y optimizar tu flujo de trabajo con YAMLResume.

## samples

[`@yamlresume/samples`](./ecosystem/samples) proporciona un catálogo de
currículums de ejemplo seleccionados para puestos comunes, cada uno traducido a
12 idiomas.

- Impulsa el comando `yamlresume new --sample` y el subcomando `yamlresume
  samples list`.
- Expone APIs de consulta para filtrar los currículums de ejemplo por idioma,
  categoría o etiqueta.
