---
title: Plantillas
description: Elige la plantilla Typst Jake integrada y configúrala con `layouts[].template`.
---

Puedes listar todas las plantillas de YAMLResume, incluidas las plantillas
Typst, con `yamlresume templates list`:

```console
$ yamlresume templates list

| layouts.[].template | Engine | Template Name | Description                                                       |
| ------------------- | ------ | ------------- | --------------------------------------------------------------- |
| jake                | typst  | Jake's Resume | A simple, straight-forward resume template based on Jake's Resume |
```

El motor Typst usa `jake` de forma predeterminada. Selecciónala explícitamente
con `layouts.[].template`:

```yml lineNumbers title="resume.yml"
layouts:
  - engine: typst
    template: jake
```
