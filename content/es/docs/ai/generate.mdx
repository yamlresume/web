title: Generar
---

El comando `yamlresume ai generate` genera un archivo de currículum completo y
realista a partir de un puesto e idioma de destino.

```console
$ yamlresume ai generate --help
Usage: yamlresume ai generate [options] <filename>

generate a new resume with AI

Arguments:
  filename                   output filename

Options:
  -p, --position <position>  target position or job title
  -l, --language <language>  target locale language
  -m, --model <model>        AI provider model to use
  -b, --base-url <url>       AI provider base URL
  -r, --retry <count>        maximum retries when validation fails (default: 2)
  -h, --help                 display help for command

Environment variables:

  Required (one API key for the selected cloud provider):
    DEEPSEEK_API_KEY          DeepSeek API key
    OPENAI_API_KEY            OpenAI API key
    MOONSHOT_API_KEY          Kimi (Moonshot AI) API key

  Optional:
    OLLAMA_HOST               Ollama host for local models
    YAMLRESUME_AI_MODEL       model override (overridden by --model)
    YAMLRESUME_AI_BASE_URL    API base URL override (overridden by --base-url)
```

## Proveedores compatibles

YAMLResume admite múltiples proveedores de LLM a través de endpoints compatibles
con OpenAI. El proveedor se infiere de las variables de entorno:

| Proveedor                                      | Variable de entorno requerida | Modelo predeterminado | Sustituciones opcionales                        |
| ---------------------------------------------- | ----------------------------- | --------------------- | ----------------------------------------------- |
| [DeepSeek](https://www.deepseek.com/)          | `DEEPSEEK_API_KEY`            | `deepseek-v4-flash`   | `YAMLRESUME_AI_MODEL`, `YAMLRESUME_AI_BASE_URL` |
| [Kimi](https://www.moonshot.cn/) (Moonshot AI) | `MOONSHOT_API_KEY`            | `kimi-k2.6`           | `YAMLRESUME_AI_MODEL`, `YAMLRESUME_AI_BASE_URL` |
| [Ollama](https://ollama.com/) (local)          | `OLLAMA_HOST`                 | `llama3.2`            | `YAMLRESUME_AI_MODEL`, `YAMLRESUME_AI_BASE_URL` |
| [OpenAI](https://openai.com/)                  | `OPENAI_API_KEY`              | `gpt-5`               | `YAMLRESUME_AI_MODEL`, `YAMLRESUME_AI_BASE_URL` |

## Ejemplos

Establece la clave de API de un proveedor y ejecuta:

```console
$ export OPENAI_API_KEY=sk-...
$ yamlresume ai generate --position "Software Engineer" --language en resume.yml
```

Sobrescribe el modelo y la URL base mediante opciones de CLI:

```console
$ yamlresume ai generate \
    --position "Registered Nurse" \
    --language en \
    --model gpt-5 \
    --base-url https://custom.openai.endpoint/v1 \
    resume.yml
```

O mediante variables de entorno:

```console
$ export YAMLRESUME_AI_MODEL=gpt-5
$ export YAMLRESUME_AI_BASE_URL=https://custom.openai.endpoint/v1
$ yamlresume ai generate --position "Registered Nurse" --language en resume.yml
```

### `--retry`

La generación se valida contra el [esquema de YAMLResume](/docs/compiler/schema)
después de cada intento. Si la validación falla, los errores se retroalimentan
al modelo y se reintenta la generación. El número máximo de reintentos es 2 por
defecto.

Puedes personalizarlo con la opción `-r, --retry`, que acepta un entero no
negativo. Por ejemplo, para permitir hasta 5 reintentos para un puesto
complicado:

```console
$ yamlresume ai generate \
    --position "Software Engineer" \
    --language en \
    --retry 5 \
    resume.yml
```

Usa `--retry 0` para desactivar por completo los reintentos y fallar rápidamente
ante el primer error de validación.

## Cómo funciona

`yamlresume ai generate` construye un prompt detallado a partir de las reglas
del [esquema de YAMLResume](/docs/compiler/schema) y un currículum de ejemplo,
luego le pide al LLM que produzca un currículum completo. El prompt instruye al
modelo a:

- Generar solo YAML válido, sin cercas de markdown.
- Mantener los comentarios YAML para que el archivo generado siga siendo
  amigable para la validación en editores/IDE.
- Seguir todas las restricciones del esquema, como longitudes de campo,
  formatos de fecha, valores de enumeración y URL válidas.
- Inventar contenido original y realista adaptado al puesto e idioma de destino,
  sin copiar los datos personales del currículum de ejemplo.

El texto generado se analiza y valida. Si la validación falla, se le pide al
modelo que corrija los errores y lo intente de nuevo, hasta el límite de
reintentos configurado.

## API programática

El paquete [`@yamlresume/ai`](https://www.npmjs.com/package/@yamlresume/ai)
también expone una API programática para generar currículums:

```ts
import { generateResume } from "@yamlresume/ai";
import { openai } from "@ai-sdk/openai";

const model = openai("gpt-5");

const yaml = await generateResume("Software Engineer", "en", { model });
```
