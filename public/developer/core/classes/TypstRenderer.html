    ProtectedgetCJKFontRegions

    • getCJKFontRegions(): string[]

      Get the preferred Noto CJK font regions for the resume language, in order of preference. CJK characters get the wrong glyph variants when rendered with the wrong regional font (e.g. Japanese kanji with an SC font), so pick the region matching the locale.

      Mirrors the logic of the LaTeX renderer's getCJKFontRegions.

    ProtectedgetNativeCJKFonts

    • getNativeCJKFonts(region: string): string[]

      Get OS-shipped CJK font families for a region.

      These are fallbacks for systems without Noto CJK installed. Typst's implicit fallback can otherwise pick a font with unusable vertical metrics: macOS resolves zh-hant-hk to Osaka, whose zero ascent/descent collapses the line height and makes adjacent lines overlap.

    ProtectedrenderFontList

    • renderFontList(): string

      Render the font fallback list for #set text(font: ...).

      Typst picks the first available font in the list, so user-configured font families take precedence, followed by the Typst-bundled Libertinus Serif (the successor of Linux Libertine, the default font of the LaTeX templates), then Noto CJK fonts resolved per locale language, then the native CJK fonts shipped by the host OS.

      Returns string

      • Defined in packages/core/src/renderer/typst/base.ts:127

    ProtectedrenderUrl

    • renderUrl(url: string): string

      Render a URL in the URL position based on showUrls setting.

      When showUrls is true, returns the URL formatted as a link showing the raw URL text (analogous to LaTeX's \url). When showUrls is false, returns an empty string (the URL is hidden and should be rendered as a clickable link on the adjacent text via renderLinkedText instead).

      • url: string
